# 0003: 解析手順の正本

- 状態：採用
- 決定日：2026-10-27
- 正本：`研究方針/解析手順２.pdf`（「ロードセルの動特性解析と入力波形推定」）
- 基本フロー：実測出力の読み込みと減衰波形確認、FFTによるモード候補抽出、データから判断した任意モード数の2次系重ね合わせによる伝達関数推定、伝達関数から微分方程式を導出、出力のフーリエ級数を微分方程式へ代入し入力の周期的な特解を推定する。
- 比較：最高使用周波数を4条件以上設定し、ナイキスト周波数以下で入力推定を比較する。各条件について波形、最大値、最小値、ピーク時刻を記録する。
- 制約：打撃を単位インパルスとみなす仮定と限界を明記する。入力が未校正ならNと表記しない。符号反転、平均値減算、周波数除外、解析区間、対象チャンネルを無断で変更しない。
- 未実装：この記録では解析コードを変更していない。次の実装タスクで、対象CSV・チャンネル・サンプリング条件・校正状態を確認してから実装する。
