# 実験データの管理

- `versioned/`：共有・保存の許可を得た小さなサンプルCSVなど。GitHubのPrivateリポジトリで履歴管理する。追加前に機密情報とサイズを確認する。
- `external/`：原測定データ、大容量、機密データ。Git対象外。研究室が認めた外部保存先に正本を置き、必要なタスクへ安全に配置する。自動ダウンロードや共有は未設定。

Git管理するデータには実験ID、取得日、装置、単位、サンプリング条件、校正情報、文字コード、欠損値の意味と利用範囲を添える。不明な値は推測せず未確認と記録する。外部データの所在は秘密のURLや資格情報を含めず識別子で記録する。

既存の各フォルダにあるCSVは既にGit追跡済みの従来資産。新しい区分への移行・追跡解除はまだ行っていない。
