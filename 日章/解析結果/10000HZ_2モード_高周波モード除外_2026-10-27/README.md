# 日章 10000 Hzデータ - 2モード再解析

## 解析方針
従来の3モードモデルから高周波側の第3モードを除外し、低周波側の2モードだけで伝達関数を再構築した。
入力推定では同一の2モード伝達関数を用い、FFTの最高使用周波数だけを変更した。

使用した最高周波数:
500, 1000, 1500, 2000, 2100, 2200, 2300, 2400, 2450, 2500, 3000 Hz

サンプリング周波数: 10000 Hz
解析時間: 0.5 s
FFT点数: 5000
周波数分解能: 2 Hz
ベースライン補正: 先頭300点平均 -0.01304333 V を減算
出力符号反転: なし

## 伝達関数

```math
G(s)=\sum_{r=1}^{2}\frac{K_r\omega_r^2}{s^2+2\zeta_r\omega_rs+\omega_r^2}
```

通分すると、

```math
G(s)=
\frac{
2.48617770\times10^6 s^2
+1.14888796\times10^8 s
+1.10552753\times10^{12}
}{
s^4
+8.40840705\times10^1 s^3
+4.04670950\times10^6 s^2
+1.85832217\times10^8 s
+1.10552753\times10^{12}
}
```

したがって、

```math
D(s)O(s)=N(s)I(s)
```

より、

```math
O^{(4)}
+84.0840705O^{(3)}
+4.04670950\times10^6O''
+1.85832217\times10^8O'
+1.10552753\times10^{12}O
=
2.48617770\times10^6I''
+1.14888796\times10^8I'
+1.10552753\times10^{12}I
```

を用いて周期的特解を周波数成分ごとに求めた。

## 観察
2000 Hz以降、最高使用周波数を上げるほど推定入力の振幅が連続的に増加する。
特に3000 Hzでは最大・最小とも急激に増大している。
2モードモデルでは高周波側で |G(jω)| が小さくなるため、逆作用 1/G(jω) が高周波成分を強く増幅することが主因と考えられる。

高周波モードは伝達関数には含めていない。2400〜2500 HzまでFFT成分を使用することと、高周波モードをモデルに採用することは別の処理である。
