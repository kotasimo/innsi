# 手計算で理解する1モード同定

対象は「成功3回目.CSV」のZ方向波形で、最も大きい約830 Hzの振動だけを1自由度系として扱う。

## 1. 波形から2つの正のピークを読む

- 1個目: `t1 = 0.0013 s`, `x1 = 2.3419 V`
- 9個目: `t9 = 0.0110 s`, `x9 = 1.5791 V`
- この間の周期数: `n = 8`

## 2. 周期と周波数

`T = (t9 - t1) / n`

`T = (0.0110 - 0.0013) / 8 = 0.0012125 s`

`fd = 1 / T = 824.74 Hz`

## 3. 対数減衰率

`delta = ln(x1 / x9) / n`

`delta = ln(2.3419 / 1.5791) / 8 = 0.04926`

## 4. 減衰比

`zeta = delta / sqrt((2*pi)^2 + delta^2)`

`zeta = 0.00784 = 0.784 %`

## 5. 固有振動数

`fn = fd / sqrt(1 - zeta^2)`

`fn = 824.77 Hz`

`wn = 2*pi*fn = 5182.17 rad/s`

## 6. ゲイン

FFTで読んだ共振点ゲインを `Hpeak = 0.014165` とする。

`K = 2*zeta*sqrt(1-zeta^2)*Hpeak`

`K = 0.0002221`

## 7. 伝達関数

`H(s) = K*wn^2 / (s^2 + 2*zeta*wn*s + wn^2)`

したがって、1モード手計算モデルは

`H(s) = 5964.5 / (s^2 + 81.26*s + 2.685e7)`

となる。

## この結果の扱い

この計算では、実際には複数含まれている振動を約830 Hzの1モードだけと仮定した。そのため、ピークを選ぶ範囲によって減衰比が変わる。手計算は同定の流れを理解するために使い、最終値は複数モードを分離した計算結果と比較する。
